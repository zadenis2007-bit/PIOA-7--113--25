Описание проекта

Этот проект — простая база данных, которая работает в памяти.
Это значит, что все данные хранятся только во время работы программы и не сохраняются в файлы.
В базе данных хранится одна таблица с записями.

Структура проекта

Проект состоит из одного файла:
`main.py` — здесь находится вся программа: база данных и консольное меню

Что умеет программа

1. Добавлять записи
Можно добавить запись с:
- именем
- возрастом
(ID добавляется автоматически)

2. Показать все записи
Можно вывести все данные из базы.

3. Поиск по имени
Можно найти записи по имени.

4. Обновление записи
Можно изменить имя и возраст по ID записи.

5. Удаление записи
Можно удалить запись по ID.

Обработка ошибок

В программе есть простая обработка ошибок:
- если запись не найдена — выводится сообщение "Not found"
- если введены неправильные данные — программа не падает
- если выбрать неправильный пункт меню — выводится "Wrong input"

Как запустить

Требования:
- Python 3

Запуск:

- терминал:
python main.py
