Описание проекта

Этот проект — простая база данных, которая работает в памяти.
Это значит, что все данные хранятся только во время работы программы и не сохраняются в файлы.
В базе данных хранится одна таблица с записями.

Структура проекта

Проект состоит из следующих файлов:
- main.py - точка входа в программу
- tui.py - консольный пользовательский интерфейс
- database.py - реализация базы данных и таблиц

Что умеет программа

1. Добавлять записи
Можно добавить запись с:
- именем
- возрастом
(ID добавляется автоматически)

2. Показать все записи
Можно вывести все данные из базы.

3. Поиск по имени
Можно найти записи по заданным полям.

4. Обновление записи
Можно изменить данные по ID записи.

5. Удаление записи
Можно удалить запись по ID.

Обработка ошибок

В программе реализована обработка основных ошибок пользовательского ввода:
- если запись с указанным идентификатором не найдена, выводится сообщение "Not found"
- при вводе нечислового значения идентификатора выводится сообщение об ошибке, программа продолжает работу
- при вводе некорректного возраста выводится сообщение об ошибке
- при попытке добавить запись с пустым именем выводится сообщение об ошибке
- при выборе несуществующего пункта меню выводится сообщение "Wrong input"

Как запустить

Требования:
- Python 3.10 или новее

Запуск:

- терминал:
python main.py
