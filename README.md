Описание проекта

Этот проект представляет собой простую базу данных, которая работает в памяти.
Все данные хранятся только во время работы программы и не сохраняются в файлы.
Проект является улучшенной версией предыдущей лабораторной работы и теперь использует классы и тестирование.

Структура проекта

- `main.py` — консольное приложение 
- `database.py` — логика базы данных 
- `tests.py` — автоматические тесты

Функциональность

Добавление записей
Можно добавить запись с:
- именем
- возрастом
ID создаётся автоматически

Просмотр всех записей

Можно вывести все записи из базы данных

Поиск по имени

Можно найти записи по имени

Обновление записи

Можно изменить имя и возраст по ID

Удаление записи

Можно удалить запись по ID

Сортировка

Есть сортировка записей:
- по id
- по имени
- по возрасту

Можно сортировать:
- по возрастанию
- по убыванию

Тестирование

В проект добавлены автоматические тесты (unittest).

Они проверяют:
- добавление записей
- поиск
- обновление
- удаление
- сортировку

 Запуск проекта

Запуск программы:

-терминал:
python main.py
